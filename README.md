# Carefree Caravaneers — Member Rally Portal Handover

## Purpose

This document explains the Carefree Caravaneers Member Rally Nomination Portal and its management arrangements.

It is intended to assist the next Rally Coordinator taking over in July 2027.

## 1. Member Rally Portal

**Website:** https://rallyprogram.github.io/carefree-member-portal/

**GitHub repository:** https://github.com/RallyProgram/carefree-member-portal

The portal allows club members to access their rally information and submit YES, NO or MAYBE nominations.

Members access the portal using their individual membership links.

**Important:** Existing member links must remain operational throughout the handover.

## 2. Website Hosting

The portal is hosted using GitHub Pages.

Current publishing settings:

- Branch: main
- Folder: / (root)
- HTTPS: Enabled
- Custom domain: None

The repository contains the portal's HTML files, installation instructions, icons and web app configuration.

## 3. GitHub Access

Current repository owner: RallyProgram.

At the time of this review, no additional collaborators have been appointed.

Before July 2027, appropriate access must be arranged for the incoming Rally Coordinator.

Do not share passwords or personal authentication codes.

## 4. Supabase Database

The portal works with the club's Supabase-based rally management system.

Member access links and rally nomination information must be protected.

The incoming coordinator will need appropriate authorised access to the relevant Supabase project.

Do not replace or regenerate existing member links unnecessarily.

## 5. Coordinator Handover Checklist

Before transferring responsibility:

- [ ] Confirm the incoming coordinator has access to the club's rally coordinator email.
- [ ] Arrange appropriate GitHub repository access.
- [ ] Arrange appropriate Supabase access.
- [ ] Confirm the Member Rally Portal opens correctly.
- [ ] Test an existing member's personal access link with their permission.
- [ ] Confirm YES, NO and MAYBE nominations operate correctly.
- [ ] Check the portal's mobile installation instructions.
- [ ] Confirm backup and recovery procedures.
- [ ] Record the responsibilities of the outgoing and incoming coordinators.

## 6. Security

Never place passwords, recovery codes, personal member links or database access tokens in this public repository.

The incoming coordinator should use their own authorised accounts wherever practical.

## 7. Handover Status

**Preparation in progress — November 2026.**

Existing systems and member links should remain unchanged until the handover arrangements have been tested and approved.
